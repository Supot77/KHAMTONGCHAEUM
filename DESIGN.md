# คำต้องเชื่อม

Game-night word tiles. Audience: Thai-speaking friends on phones; primary job: submit the next noun before time runs out.

- Canvas #F3F4FE; ink #29294B; primary #6356D8; mint #DFF4D6; coral #F5B8AA; white #FFFFFF.
- Display Mitr; body Sarabun with Thai system fallback. Avoid letter spacing in Thai. Numerals use tabular figures.
- Desktop board: player list / current word and input / chain and reset history. Mobile: current word, input, chain, players.
- Signature: linked, slightly offset word tiles. Reserve decorative movement for a tiny submission transition; respect reduced motion.
- Controls at least 44px high; clear focus; semantic forms and live announcements. Pending scores visibly distinct.
