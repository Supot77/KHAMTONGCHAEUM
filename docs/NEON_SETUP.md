During the later installation audit, all of these were already present. **Nothing was reinstalled, no duplicate project-level MCP config was created, and no existing plugin setting was overwritten.** Installed skill updates are handled by the plugin rather than a duplicate `neon skills` installation.

MCP tools may require Codex to reload its plugin connections. Installation/configuration is verified; a live MCP operation was not available in the current tool set. The authenticated CLI and actual Postgres connection were used for service verification.

## Project configuration changes

1. `.neon` links the existing org `org-calm-resonance-38081632`, project `lingering-hat-67473382` and `production` branch. It is ignored by Git.
2. `neon.ts` was initially generated by `neon init`. Its default branch policy remains in place. The explicit `auth: false` declaration was removed before deployment so the app requests only Postgres without disabling an existing identity provider. The subsequent audit left this file unchanged.
3. `neon deploy` reported **No changes** to branch policy/services and pulled `DATABASE_URL`, `DATABASE_URL_UNPOOLED` and `NEON_BRANCH` into the existing `.env.local`. Gemini variables were preserved; no secret values are documented or committed.
4. `database/schema.sql` and `scripts/setup-db.mjs` create the two new app tables after inspection confirmed no existing user tables. They do not drop, truncate or seed existing user data.
5. `lib/storage.ts` uses a shared `pg` pool with the pooled URL and Vercel's `attachDatabasePool`. Schema setup uses the direct URL. `lib/sql-store.ts` keeps all values parameterized and implements compare-and-swap updates.
6. Added `pg`, `@vercel/functions`, `@types/pg`, and CLI-generated `@neon/config` / `@neon/env` dependencies. Removed the earlier HTTP driver in favor of the installed skill's Vercel recommendation.
7. Added live online/AI smoke tests and updated README, environment example and verification records. Local-only SQLite development is retained; it is never used as a deployed Vercel room store.

No Auth, Data API, AI Gateway, Object Storage, Functions or Realtime service was enabled for this app. Existing unrelated credentials/services were left intact. Gemini remains the selected free-tier LLM provider.
